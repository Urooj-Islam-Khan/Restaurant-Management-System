# 🍽️ Restaurant Management System (Python Console App)

This is a console-based restaurant management system developed in Python using the `os`, `random`, and `file handling` modules. The system supports two roles: **Admin** and **User**.

---

## 💡 Features

### 👨‍💼 Admin Panel
- View restaurant menu
- Add new items to existing or new categories
- Remove items from the menu
- Update item name or price
- View customer billing records (from `userBill.txt`)
- Pin-based admin authentication

### 👥 User Panel
- Browse the complete restaurant menu (from `menu.txt`)
- Place orders using item IDs
- Automatically generate bills with total price
- Store bill history to `userBill.txt`
